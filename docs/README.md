# Tài liệu PayoutHub

Điểm vào duy nhất cho mọi tài liệu học. Thêm file mới thì thêm một dòng ở đây.

## Tiến độ

| File | Nội dung |
|---|---|
| [PLAN.md](PLAN.md) | Milestone M1–M7, checklist, lab, parking lot. Nguồn sự thật về tiến độ |
| [LEARNING-LOG.md](LEARNING-LOG.md) | Nhật ký từng phiên: đã làm, chỗ yếu, kết quả quiz |

## Quy ước

- Sổ tay = câu hỏi ngắn kiểu phỏng vấn. Note = bài đào sâu khi sổ tay chưa đủ. Không chép nội dung giữa hai bên, chỉ link.
- Note mới: đặt ở `notes/<chu-de>.md`, thêm vào bảng Notes ở trên và thêm `→ note` vào dòng tương ứng trong `handbook-index.md`.
